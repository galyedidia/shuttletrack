# Build Project

Follow these steps to install dependencies, run TypeScript verification, and build the Next.js application:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run TypeScript Check**:
   ```bash
   npm run typecheck
   ```

3. **Build Application**:
   ```bash
   npm run build
   ```
