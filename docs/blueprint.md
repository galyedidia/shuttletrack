# **App Name**: ShuttleTrack

## Core Features:

- Attendance Logging: Coaches can record athlete attendance (present/absent) for training sessions.
- Session Details: Input training session date, athlete group, and individual ratings (1-5).
- Absence Details and Comments: Coaches can add specific absence reasons (vacation, injury, illness, etc.) and individual comments for each athlete.
- Comment analysis tool: A tool to suggest common themes and sentiments that frequently appear in the coaches' comments for athletes based on keywords. This can quickly show how a player is progressing.
- Club Configuration: Manager to configure club groups/levels, assign athletes, manage coaches, and define absence reasons.
- Branding: Manager can upload the club's logo.
- Localization: The Application will support display in Hebrew.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) evoking energy, focus, and precision, mirroring the agility of badminton.
- Background color: Light blue (#E0F7FA) providing a clean and unobtrusive backdrop.
- Accent color: A bright yellow (#FFDA63), similar to the color of the shuttlecock, which highlights key actions and calls attention to important data points.
- Font: 'PT Sans' (sans-serif) for both headlines and body, ensuring readability and a modern aesthetic.
- Use clear, intuitive icons representing attendance status, absence reasons, and rating levels. Icons should be consistent with the app's overall style and easy to understand at a glance.
- Maintain a clean, well-organized layout, ensuring information is easily accessible on both mobile and tablet devices. Utilize clear sectioning and intuitive navigation to streamline the user experience.
- Subtle animations and transitions can be used to provide feedback on user actions and improve the app's overall feel. Avoid excessive animations that may distract from the app's core functionality.
